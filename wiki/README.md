# Wiki

The wiki is where everything about this project beyond the code is meant to live, for people and agents alike. It is under construction: its structure and content are not decided, and will be mapped out together. Nothing here is the final shape, and this page says only what is in it right now.

## What is here now

- [`transcripts/`](transcripts/README.md) — meetings, written up as the knowledge they presented, and how that is done. The main material so far.

- [`log/`](log/README.md) — one entry per session or meeting that changed what the wiki holds.

- [`the-rule/`](the-rule/README.md) — the rule, with its practice and skill: how knowledge is written. Transcripts are written under it, but it is not adopted as the wiki's structure. It is mounted as a git submodule, [`Cwejman/the-rule`](https://github.com/Cwejman/the-rule).

## Reading order, for now

This page, then [`transcripts/README.md`](transcripts/README.md). Read the rule when writing. The log is history, read when you need to know how something came to be.
