# Hjulverkstan Code Test

[Hjulverkstan](https://github.com/Hjulverkstan/hjulverkstan) is an open-source project built by Alten for Save the Children. It has been developed by people with varying levels of experience, from interns to senior developers, and the quality varies accordingly. There is no deliberately planted issue to find.

## Instructions

### 1. Make a private copy.

Create a private copy of the repository on your GitHub. GitHub keeps forks of public repositories public, so a regular fork will not do.

### 2. Raise three things.

Go through the repository and choose the three things that you, as a contributor, find most important to raise. At least one must concern the backend (`api/`); the others may concern the backend, the infrastructure (`cdk/`) or the pipelines (`.github/`). They do not need to be spread across the areas, choose by importance. Tests are out of scope, they are being worked on separately.

Write each of the three as an issue in your repository, and make their order of priority clear.

### 3. Implement one.

Pick one of the three and open a pull request for it in your repository. Keep it small; if the topic is larger than that, do the first piece so that someone else could continue.

### 4. Hand in.

Invite [Jona Cwejman](https://github.com/Cwejman) to the repository. We go through your issues and pull request together in the interview.
